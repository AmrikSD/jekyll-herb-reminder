# Jekyll Herb Reminder

This is a simple plugin that will remind you to keep a herb in your inventory at all times, for [Dr. Jekyll.](https://oldschool.runescape.wiki/w/Dr_Jekyll#Rewards)

> [!WARNING]
> If you are not receiving notifications, please makes sure your Runelite settings for alerts are configured correctly. You can see instructoins on how to do that [here](https://github.com/AmrikSD/jekyll-herb-reminder/issues/2#issuecomment-2403524432).

https://runelite.net/plugin-hub/show/advanced-notifications is another fantastic plugin that can be used to achieve a similar outcome.
